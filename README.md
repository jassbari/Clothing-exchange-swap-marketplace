# SwapStyle – Clothing Exchange & Swap Marketplace

SwapStyle is a full-stack MERN web application that provides a sustainable platform for users to exchange and swap pre-loved clothing instead of buying new clothes.

## 🌱 Project Overview

SwapStyle helps users refresh their wardrobe while promoting sustainable fashion.

Users can:
- Create an account and sign in
- Browse available clothing items
- List their own pre-loved clothing
- Request clothing swaps
- Manage their listings
- Track pending and completed swaps
- View their profile and activity
- Search for clothing items

The goal is to make clothing exchange simple, affordable, and environmentally friendly.
